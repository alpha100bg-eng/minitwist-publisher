Privacy Policy

MINI TWIST Publisher — last updated September 18, 2026

1. What this application is

MINI TWIST Publisher is a private tool operated by the owner of the MINI TWIST YouTube channel. It uploads and schedules videos that the owner created, on the owner's own YouTube channel. It is not offered to the public, and its only user is the channel owner.

2. YouTube API Services

This application uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. Data the application accesses

The application requests a single permission: https://www.googleapis.com/auth/youtube.upload. It uses it only to upload videos to the authorized channel and to set each video's title, description, tags, privacy status and scheduled publication time.

It does not read, collect or store comments, subscribers, viewer information, analytics, or any other data from the YouTube or Google account.

4. Data the application stores

  • An OAuth authorization token, kept as an encrypted secret in the environment that runs the application, so that it can upload on the owner's behalf.
  • The video files and their titles and descriptions, prepared by the channel owner before upload.

The application collects no personal data about viewers or any other person. This website sets no cookies and uses no analytics or tracking. It is hosted on GitHub Pages, which may keep technical logs such as IP addresses as described in the GitHub Privacy Statement.

5. Sharing

No data is sold, rented or shared with third parties. Video files and their metadata are sent only to YouTube, which is necessary to upload them.

6. Retention and deletion

The authorization token is kept only while the owner allows the application to access the channel. It is deleted when access is revoked or when the application is discontinued.

7. Revoking access

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. Once revoked, the application can no longer upload anything.

8. Changes to this policy

If this policy changes, the updated version will be published on this page with a new date.

9. Contact

Questions about this policy can be submitted through the project's issue tracker.
